# 💳 Loan Default Risk Analysis

## 📌 Overview
This project focuses on analyzing loan application data to identify patterns related to default risk and support better lending decisions.

---

## 🎯 Objectives
- Perform exploratory data analysis (EDA)
- Identify key factors influencing loan default
- Analyze customer and financial attributes
- Derive insights for risk assessment

---

## 🛠️ Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  

---

## 📊 Key Steps
- Data cleaning and preprocessing  
- Handling missing values  
- Exploratory data analysis (EDA)  
- Feature analysis and pattern identification  

---

## 📈 Key Insights
- Customer and financial attributes influence repayment behavior  
- Certain factors increase the likelihood of loan default  
- Data-driven insights can support better lending decisions
